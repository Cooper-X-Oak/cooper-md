# 城市像一台缓慢重启的机器

清晨六点半，街边第一家咖啡店还没有完全亮起来。玻璃门内侧贴着前一晚留下的水汽，吧台上的金属器具反着冷光，像一组尚未启动的仪表。城市在这个时刻没有完整醒来，只是把一些必要的部件先打开：公交站、便利店、早餐摊，以及那些比闹钟更早出门的人。

所谓现代生活，很少是由宏大的变化构成的。它更多藏在一些细小的调整里：一条通勤路线被重新规划，一家老店换了招牌，一段关系停止更新，一个人开始认真记录自己的支出。**真正改变生活节奏的，往往不是事件本身，而是事件之后形成的新习惯。**

这也是中文长文最容易被忽略的部分。很多文章在观点上足够清楚，却在阅读节奏上过于接近 Markdown 预览：段落之间没有呼吸，重点文字像临时加粗，链接和分隔线只是技术标记。我们希望 Cooper 的现代专栏排版更接近一份经过编辑处理的出版物：克制、清楚，并且能让读者愿意继续往下读。

## 一、正文应该先建立信任

一篇文章的第一屏通常不适合过度装饰。读者需要先确认三件事：这篇文章在说什么、语气是否可靠、继续读下去是否值得。排版在这里不应该替作者表演，而应该降低进入成本。

因此，正文段落需要稳定的行距和段距。行距太紧会让中文笔画互相挤压，段距太大又会把连续论述切碎。比较理想的状态，是读者在手机上单手滑动时，眼睛能自然抓住下一行，同时不会觉得页面松散。

这里有一个简单判断：如果把一段 120 字左右的文字放进预览区，读者不需要刻意放慢速度，也不会在换行处丢失位置，那么正文基线大体就是健康的。

### 强调不应该变成喧哗

中文专栏里的 **粗体** 更适合作为结构性强调，而不是情绪性标记。它可以帮助读者抓住句子的骨架，但不应该在视觉上抢过标题。相比主题色强调，深色粗体更稳，也更接近出版物里的重点标注。

_斜体_ 在中文里要更谨慎。很多系统字体的中文斜体并不好看，但它仍然可以作为弱强调出现，尤其适合表示语气、概念名称或转述。它的颜色应该略弱于正文，而不是突然变浅到像注释。

#### 更小层级的编辑提示

四级标题适合放在段落内部的小分组之前。它应该能被读者扫到，但不需要像章节标题一样占据视觉中心。

链接也一样。公众号里很多外链最终不可点击，视觉上却仍然承担“引用来源”或“延伸阅读”的功能。像 [doocs/md](https://github.com/doocs/md) 这样的链接，应该可识别，但不要像按钮一样跳出来。

## 二、章节之间要有停顿

分隔线不是为了把页面切成几张卡片，而是为了给读者一个短暂停顿。尤其在观点转向、案例切换、结论之前，细线可以让文章有一点“换气”的感觉。

它应该足够轻，轻到不会成为画面中心；也应该足够明确，明确到读者知道这里发生了结构变化。相比复杂图形，一条稳定的细线更适合微信环境。

> 一段好的引用，不需要很大的背景块。它只需要告诉读者：这不是正文的主声部，而是被编辑插入的一段旁白。

## 三、后续继续观察的元素

下面这些内容不属于第一阶段的正文基线，但会留在样张里，方便后续继续打磨标题系统和块元素。

- 列表项目需要和正文保持同一套灰度，不要像后台表单。
- 代码块应该像编辑插入物，而不是装饰卡片。
- 表格要优先保证可读性，再考虑风格。

```ts
const typography = {
  theme: 'cooper',
  style: 'modern-column',
  principle: 'style changes, content stays',
}
```
