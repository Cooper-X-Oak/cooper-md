# 字体不是装饰：一次现代中文排印观察

一篇文章的气质，往往不是从图片开始的，也不是从标题旁边那条彩色竖线开始的。它更早发生在读者还没有意识到的时候：第一行字是否站得住，段落之间是否有呼吸，标点和中西文混排是否自然，重点文字是否像句子的骨架，而不是一块临时贴上的标签。

我们把这种状态称为“排印感”。它不是把文章做得更花，也不是让每一段都拥有独立的视觉造型。恰恰相反，真正高级的中文排版通常很安静。它让大部分元素退后，只在少数位置给出准确的姿态：一个标题的重量，一段引文的偏移，一条细线的停顿，或一段图注的低声说明。

Cooper 的现代专栏主题需要面对的 benchmark，不是普通公众号模板，而是那些来自字体、字库、出版和设计文化语境的文章。它们有一个共同点：**文字不是被样式包裹的内容，而是版面的主要材料。** 主题要做的事情，是把 Markdown 文稿整理成一篇可以被认真阅读的中文文章。

## 一、正文先建立文字的纹理

中文长文最容易失去的不是信息，而是纹理。段落如果太紧，汉字的笔画会在手机屏幕上互相压迫；段落如果太松，论述就会被切成一组没有关系的卡片。好的正文排版，需要让读者在滑动时一直知道自己在哪里，也愿意继续往下读。

这件事听起来朴素，却很难。因为中文不是拉丁字母的连续线条，而是一组组方块字构成的灰度平面。字号、字重、行距和段距共同决定了这块灰度是否稳定。**如果整屏文字看起来像一片均匀的墨色，读者就不会被排版本身打断。**

中西混排会进一步考验主题。例如 `OpenType`、`CLREQ`、`variable font` 这些词出现在中文段落里时，不应该像从另一个系统里掉出来的碎片。它们需要被看见，但不能破坏中文正文的节奏。链接也一样，像 [The Type 的孔雀计划](https://www.thetype.com/kongque/) 这样的来源应该可识别，却不应该变成一个按钮。

### 强调应该像句子的重音

中文里的 **粗体** 更接近句子的重音，而不是情绪放大器。它应该帮助读者抓住论述的骨架，但不能比标题更响。相比把重点文字涂成主题色，稳定的深色粗体更像出版物里的标注。

_斜体_ 在中文里要更谨慎。很多系统字体并没有真正好看的中文斜体，浏览器往往只是机械倾斜字形。它仍然可以用于概念名、转述语气或轻微的旁注，但颜色和力度都应该低于粗体。

#### 小标题是段落内部的转向

四级标题不应该像一个新章节。它更像编辑在段落内部放下的路标：读者扫到它，知道论述发生了轻微转向；读者不扫它，文章也仍然可以顺畅读下去。

## 二、标题要有姿态，但不要像组件标题

很多公众号主题的问题，不是标题不清楚，而是标题太像组件。左边线、色块、底纹、图标和编号叠在一起，读者一眼就能看出“这里套了一个样式”。这样的标题很醒目，但不一定高级。

出版物里的标题通常更依赖比例：字号、字重、上下留白，以及标题和正文之间的距离。主题色可以出现，但它更像印刷里的专色，不是 UI 系统里的主按钮颜色。它出现得越少，出现时越有力量。

### 章节之间需要停顿

章节不是把文章切成几张卡片。它应该像一次换气。上一节的语气结束，下一节的论述进入，中间需要一小段安静的空气。分隔线可以承担这个任务，但线本身不应该成为画面中心。

> 好的标题不是喊出来的。它只是把文章的骨架放在正确的位置，让读者自然意识到这里有一个层级。

> [!NOTE] Benchmark 观察
> 字体与排版类媒体的文章通常不会滥用装饰。它们的设计感来自极少数准确的决定：标题的重量、正文的灰度、引文的声部，以及图注和正文之间的距离。

## 三、引用应该是第二声部

引用不是信息卡片。它更像正文旁边突然出现的另一种声音：可能是作者引用的一句话，也可能是编辑挑出来的一段旁白。如果引用被做成一块完整的灰色容器，它会变得太像产品文档里的提示框。

因此，`blockquote` 和 `markdown-alert` 应该被区分开。前者偏文学性，后者偏信息性。前者可以更轻、更像旁白；后者可以保留边框和浅底，因为它本来就是编辑提示。

```ts
const benchmark = {
  field: 'Chinese typography',
  medium: 'WeChat article',
  goal: 'quiet but memorable',
}
```

代码块也有类似问题。技术文章需要代码清楚可读，但现代中文专栏不应该被代码块拖回 IDE 截图的气质。代码应该像编辑插入的资料：边框轻、背景轻、字号略退后，读者需要时可以读，不需要时也不会被它抢走。

## 四、资料元素要像编辑整理过

表格、列表、图片和图注，是最容易暴露“网页组件感”的地方。它们当然要清楚，但清楚不等于粗边框、重底色和强对比。出版物里的资料元素通常更像被编辑整理过的信息，而不是后台界面里的控件。

| 元素  | 普通主题倾向 | 出版物 benchmark |
| ----- | ------------ | ---------------- |
| 引用  | 灰底卡片     | 第二声部         |
| Alert | 提示组件     | 编辑说明         |
| 代码  | 工程截图     | 资料插入         |
| 表格  | 后台表格     | 整理后的信息     |
| 图注  | 小号灰字     | 低声说明         |

![孔雀计划题图](https://www.thetype.com/wp-content/uploads/2018/10/kongque-greenhero.png)

图注应该像编辑留在图片下面的一句话。它不必承担正文的重量，但也不能轻到不可读。图片、图注和下一段正文之间的距离，会决定它看起来像出版物里的插图，还是像随手插入的媒体资源。

## 五、Cooper 应该留下一个克制的记忆点

克制不等于没有性格。真正好的中文排版通常只有一两个记忆点，其他部分都很安静。对 Cooper 来说，这个记忆点不应该是复杂背景、图标或渐变，而应该来自字体排印本身。

更合适的方向，是让标题系统和引用系统成为主题的识别点：标题有稳定的重量和留白，引用像文章里的第二声部。主题色只在必要位置出现，像一支非常细的专色笔，而不是整套 UI 的按钮颜色。

如果这篇 benchmark 样张在 Cooper 主题里读起来仍然只是“干净”，那说明我们还停留在安全排版；如果它读起来安静、清楚，并且在标题、引文和图注上有一点难以言说的姿态，主题才真正接近现代中文出版物。
